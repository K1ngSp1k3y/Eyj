OrbSuiteSpoofer

Self-only cosmetic shop & Nitro suite preview, local badges, and 100 device presets for Revenge.

Install Link (Paste into Revenge)

Install in Revenge

  1. Extract the ZIP and host index.html, manifest.json, and OrbSuiteSpoofer.js on HTTPS (such as GitHub Pages).
  2. Open Discord with Revenge running.
  3. Go to Settings → Plugins → + and paste the install link above.
  4. Enable OrbSuiteSpoofer and open Settings to use the shop, badges, Nitro toggles, and 100 device presets.
